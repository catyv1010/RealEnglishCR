# Real English CR

Sitio web de la academia de ingles Real English CR. Es la parte del front-end del proyecto del curso SC-504 Lenguajes de Bases de Datos.

## De que se trata

Real English CR es una academia (ficticia) de ingles con cinco sedes en Costa Rica: San Jose, Heredia, Cartago, Alajuela y Liberia. Aca esta la parte web, o sea las paginas que ve el usuario. Mas adelante estas paginas se conectan a la base de datos en Oracle usando PHP con la extension OCI8.

## Como correrlo

1. Tener XAMPP instalado.
2. Copiar la carpeta `RealEnglishCR` dentro de `C:\xampp\htdocs`.
3. Abrir el panel de XAMPP y prender Apache.
4. En el navegador entrar a: `http://localhost/RealEnglishCR/index.html`

## Tecnologias

- HTML5, CSS3 y JavaScript
